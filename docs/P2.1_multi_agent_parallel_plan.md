
## 6. Agent A — Runtime Completion + Bridge

### 优先级

```text
P0 / Critical Path
```

这是整个 P2.1 的关键路径。

### Agent A 负责

#### Runtime Completion

分析并最小扩展：

```text
Save ACCEPTED
→ actual async Save
→ Save COMPLETED

Load ACCEPTED
→ actual Load
→ Load COMPLETED
```

现有：

```text
HH_EVENT_STATE_SAVE_ACCEPTED
HH_EVENT_STATE_LOAD_ACCEPTED
```

语义不得改变。

新增真实：

```text
*_COMPLETED
```

事件。

### Agent A 允许修改

主要：

```text
handheld/runtime/
handheld/bridge/
```

以及真正必要的最小 RA hook，例如：

```text
tasks/task_save.c
```

如果实际 completion 位于其他文件，允许修改真实 completion 所在文件。

### Agent A 禁止修改

```text
handheld/ui/
validation/p2/
validation/p2-1/input-*
.github/workflows/
Android UI
```

### Agent A 第一阶段必须回答

在代码里确认：

```text
Save 成功最终在哪里确定？
Save 失败最终在哪里确定？

Load 成功最终在哪里确定？
Load 失败最终在哪里确定？

最小 hook point 是什么？

Runtime request_id 如何关联到 async task？
```

确认后直接实现，不再询问。

### Agent A 目标架构

```text

 ↓

ACCEPTED

```
