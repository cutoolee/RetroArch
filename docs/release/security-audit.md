# 开源发布安全审计

审计日期：2026-11-15。

## 发布源码

维护者选择将当前发布版作为仓库的首个根提交。新的公开分支不继承旧提交历史；源码保留原有版权、许可证和上游致谢。

新根提交排除原始设备日志、历史验收截图、录屏、测试产物和 Xcode 源码控制元数据。上述本地文件保留，仅从公开源码清单移除。validation/ 仅保留测试和检查代码；公开工作流仅保留 GameGo Checks 与 GameGo Release。

当前源码扫描私钥、GitHub/AWS 凭据、签名文件、ROM/安装包及设备标识。公开密码学测试密钥按文件哈希确认；新生成的 Android 发布私钥只在本地忽略目录与 GitHub 加密 Actions Secrets 保存，Git 中仅保留公开证书。

## 历史审计与处理

清理前的 gitleaks 扫描检查了 64,042 次提交、约 489 MB 的历史补丁。结果包含代码常量、公开测试向量、旧设备标识及上游已经移除的凭据字段。旧历史不纳入新根提交，也不将旧扫描结果作为允许新泄漏的基线。

最终检查针对新的公开根提交执行。公开测试样例与非凭据常量使用明确规则区分，未验证的命中不得直接忽略为安全。

新根提交的严格扫描报告了 9 条代码标识符匹配，已逐条核对为 `MBEDTLS_ASN1_OID`、`_mm512_shuffle_epi32`、`_mm256_shuffle_epi32`、`RETRO_SMB2_SEC_NTLMSSP` 和 `MENU_ENUM_SUBLABEL_DISCORD_ALLOW`。它们分别是公开库常量、SIMD 函数名和菜单枚举。经维护者于 2026-11-15 明确授权，后续维护提交仅为这 5 个固定字符串添加首尾锚定的精确例外，匹配对象限定为扫描器提取的 secret 字段；其他凭据规则保持启用。已公开发行标签和源码包保持不变，其原始扫描结果仍保留。

使用与 CI 相同的 Gitleaks 8.24.3，对包含根提交的公开分支历史执行完整扫描，显式不使用本地旧忽略清单：原配置报告 9 条匹配，新配置为 0 条。另用合成样例验证 5 个精确标识符被排除，10 个相近字符串和 1 个普通凭据格式对照仍会被检测。

## 清理边界

强制更新分支、移除旧标签和删除旧候选源码包，不能保证清除 GitHub 的旧 PR 引用、缓存、其他人的克隆或上游仓库自身的历史。需要进一步删除 GitHub 保留对象时，仓库所有者应向 GitHub Support 请求敏感数据清理。

首轮候选包来自旧 commit，仅用于本次构建排障，不作为最终公开交付。最终安装包、完整对应源码和 SHA256SUMS 从新的根提交生成。
